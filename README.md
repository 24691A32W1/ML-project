# Student Academic Performance Prediction System Using Machine Learning

B.Tech mini-project. Predicts a student's final examination marks, classifies the result into a
performance category, compares four regression algorithms, and presents everything in a Streamlit dashboard.

> **Data notice:** the dataset is **synthetic** (generated by `src/generate_dataset.py`). It is not real student
> data, and the reported accuracy applies to this synthetic data only. See `data/DATA_DICTIONARY.md`.

## Quick start

```bash
# 1. (recommended) create a virtual environment
python -m venv venv
venv\Scripts\activate          # Windows
source venv/bin/activate       # macOS / Linux

# 2. install dependencies
pip install -r requirements.txt

# 3. launch the dashboard
streamlit run app.py
```

Trained models and the dataset are already included, so step 3 works immediately.
To rebuild everything from scratch:

```bash
python -m src.generate_dataset     # creates data/student_performance.csv
python -m src.train_models         # trains, compares, saves models/ + reports/
streamlit run app.py
```

Or run `run_all.bat` (Windows) / `./run_all.sh` (macOS/Linux) to do all of it in one go.
Run the tests with `python tests/test_pipeline.py`.
Use Python 3.9+ (developed on 3.12 with scikit-learn 1.9).

## How it works

1. **Data:** 1,200 synthetic records, 11 input features, target `Final_Exam_Marks`.
2. **Cleaning:** duplicates removed; rows with an invalid or missing target dropped.
3. **Pipeline (fitted on training data only):** median/mode imputation → IQR outlier clipping → standard scaling →
   one-hot encoding → zero-variance filter. Because it sits inside a scikit-learn `Pipeline`, cross-validation
   refits it on each fold, so no information leaks from validation or test data.
4. **Split:** 80:20 train/test, `random_state=42`.
5. **Models:** Linear Regression, Decision Tree, Random Forest, Gradient Boosting; the last three are tuned with
   `GridSearchCV` (5-fold).
6. **Model selection:** lowest mean 5-fold cross-validated RMSE **on the training set**. The test set is not used to
   choose the model; it only provides the final report.
7. **Classification:** predicted marks are mapped to Excellent (85–100), Very Good (70–84.99), Good (55–69.99),
   Average (40–54.99) and Needs Improvement (<40). Students in the last two are flagged for support.

> The original brief ended at "Average: 40–". The Average upper bound and the below-40 category are my
> assumption. Change `CATEGORY_BANDS` in `src/config.py` if your syllabus differs.

## Results (held-out test set, 240 students)

| Model | CV RMSE | Test MAE | Test MSE | Test RMSE | Test R² |
|-------|---------|----------|----------|-----------|---------|
| **Linear Regression** (selected) | 4.07 | 3.39 | 17.98 | 4.24 | 0.914 |
| Gradient Boosting | 4.22 | 3.47 | 19.11 | 4.37 | 0.908 |
| Random Forest | 4.30 | 3.66 | 20.72 | 4.55 | 0.901 |
| Decision Tree | 5.24 | 4.51 | 31.22 | 5.59 | 0.851 |

Category accuracy on the test set: about 77%.

**Interpretation, honestly:** Linear Regression wins because the synthetic generator is mostly linear, so a
linear model fits it well. This is a property of the simulated data, not evidence that linear models are
generally better for student marks. On real data the ranking could differ, and the R² of 0.91 should not be
expected to carry over. The most influential features were Internal Exam Marks and Previous Semester Marks,
followed by Study Hours, Assignment Score and Attendance. These reflect how the data was generated.

## Limitations

* Synthetic data; no real-world validity is claimed.
* Predictions are a support aid, not a basis for grading or disciplinary decisions.
* Importance and correlation show association, not causation.
* Gender is included as a feature because the brief lists it; its learned effect is ~0 here, and in a real
  deployment you should think carefully about fairness before using it.

## Troubleshooting

* `ModuleNotFoundError: src` → run commands from the project root folder.
* Pickle/version warnings → retrain with `python -m src.train_models` using your installed scikit-learn.
* Port busy → `streamlit run app.py --server.port 8502`.
